# 🌸 Aura Aesthetic Clinic — Medical Concierge & Online Booking Portal

> A luxury, mobile-first aesthetic & wellness clinic booking web application built with **React 19**, **Vite**, **Ant Design**, and **Tailwind CSS**.

---

## ✨ Features & Highlights

### 🧖‍♀️ Client Booking Experience
- **Interactive 3-Step Booking:** Treatment selection, date & time slot picking, and patient contact confirmation with zero prepayment required.
- **High-Resolution Photo Viewer:** Tap any treatment image or clinic gallery photo to inspect it full-screen with high-clarity zoom.
- **Verified Patient Reviews & Star Ratings:** Star ratings on treatment cards with a dedicated testimonials modal featuring genuine client feedback.
- **Post-Procedure Rating System:** Automated rating & review modal unlocked when an appointment is marked as completed by staff.
- **3-in-1 About Us & Concierge Support:** Clinic overview, medical credentials, services catalogue, and 1-tap connections to Facebook, Instagram, Email, and Phone/Viber.
- **Official BIR Registration Seal:** Prominently displayed Bureau of Internal Revenue (BIR) Seal Badge 26 with scannable QR verification.
- **Booking Tracker & QR Slip:** Instant appointment tracking by phone number or reference ID (`AURA-202611-6`), with printable check-in pass.

### 🛡️ Admin Dashboard (PIN-Protected)
- **PIN Security Portal:** Fast, customizable numeric PIN security (default: `1234`).
- **Comprehensive Overview:** Live statistics on pending, confirmed, completed, and cancelled bookings with revenue tracking.
- **Client Database & Account Blocking:** Full client directory with visit histories, spend metrics, and one-click account suspension for bogus bookings.
- **Imminent Appointment Notifications:** Automated alerts for Today and Tomorrow bookings with one-click Gmail, SMS, and Viber reminder dispatchers.
- **Direct Phone Photo Uploads:** Upload treatments and brand logos directly from a mobile camera or gallery with automated HTML5 canvas compression.
- **Anti-Loss Data Protection:** Safe JSON backup export with permanent local persistence.

## 🛠️ Tech Stack
- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **UI Components & Icons:** [Ant Design (Antd 6)](https://ant.design/) + `@ant-design/icons`
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Date & Scheduling:** [Dayjs](https://day.js.org/)
- **Effects & Feedback:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/Cebbx/aura-aesthetic-clinic.git

# Navigate into project directory
cd aura-aesthetic-clinic

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
